# GitHub documentation templates (free)

🇪🇸 [Leer en español](README.md)

The basics to make your repository trustworthy: README, contributing guide and issue forms.

**Free and open source (MIT).** Use it in your projects and your clients' projects. The files are commented in Spanish.

## What's included

- Library README
- CONTRIBUTING.md with a branching workflow and Conventional Commits
- Issue form for bugs
- Pull request template with a checklist

## Installation

```bash
git clone https://github.com/carlosp5751258-lgtm/ctrlia-plantillas-docs-github.git
cp -r ctrlia-plantillas-docs-github/.github .
cp ctrlia-plantillas-docs-github/CONTRIBUTING.md .
cp ctrlia-plantillas-docs-github/readme/README-libreria.md README.md
```
